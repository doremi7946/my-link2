# 개발 계획 (Plan)

1. **Firebase Authentication 설정**
   - `lib/firebase.ts`에 `getAuth` 및 `GoogleAuthProvider`를 추가하여 인증 기능을 초기화합니다.
2. **로그인/로그아웃 UI 구현**
   - 헤더에 구글 로그인 버튼을 추가합니다.
   - 와이어프레임(WIREFRAME.md)에 따라 로그인 전에는 안내 문구와 로그인 수단(자물쇠 버튼 등)을 표시하고, 로그인 후에는 로그아웃 버튼(🚪 로그아웃)과 사용자 프로필을 표시합니다.
3. **Firestore 경로 개인화**
   - 기존 고정 경로(`users/anonymous/links`)를 `users/{user.uid}/links`로 변경합니다.
   - 사용자가 로그인했을 때, 해당 사용자의 고유 `uid`를 사용하여 데이터를 읽고 쓰도록 수정합니다.
4. **비로그인 상태 안내**
   - 비로그인 상태일 경우, 서비스를 이용하기 위해 로그인해야 한다는 안내 문구를 화면에 표시합니다.
5. **빌드 검증**
   - 구현 후 `npm run build`를 통해 빌드 에러 여부를 점검합니다.
